# Windows
1. 打开git for Windows [Git - Install for Windows](https://git-scm.com/install/windows)
2. ![image.png](https://oss.xieea.top/img/20260726163242915.png)
   下载安装包
3. 打开安装包 一直下一步即可
# liunx
## 使用包管理器
### Debian系和Ubuntu
```
sudo apt install git-all
```
### Fedora RHEL  CentOS系
```
sudo dnf install git-all
```
# 验证
```
git --version
```
