# 前言

在开始之前，你需要准备
1. 一台常驻的服务器/主机，或就使用你的Windows电脑这里
2. 一个大模型的api
3. 一个独立思考的大脑

# Linux设备
## 第一步
ssh到你的服务器或主机
```
ssh 你的主机ip
#然后输入密码 输入时不显示
```
## 引导安装
使用的官方脚本，来自[Linux/MacOS 安装 |docs.ST.app](https://docs.sillytavern.app/installation/linuxmacos/)
```
git clone https://github.com/SillyTavern/SillyTavern-Launcher.git

cd SillyTavern-Launcher

chmod +x install.sh && ./install.sh

chmod +x launcher.sh && ./launcher.sh
```
![image.png](https://oss.xieea.top/img/20260726164140493.png)

## 手动脚本安装
```
git clone https://github.com/SillyTavern/SillyTavern -b release

cd SillyTavern

start.sh
```
## docker
1. 先克隆仓库
```
git clone https://github.com/SillyTavern/SillyTavern
```
2. 
```
cd ~/SillyTavern
docker compose up
```
